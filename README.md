# FIPMS — نظام متابعة الأراضي (متعدد المستخدمين)

نظام متابعة أراضٍ سحابي: سجل قطع، حالات ذكية، أرشفة، تقارير مخصصة، طلبات ضريبة التصرفات وتسجيل عيني مع متابعة لكل قطعة، وصلاحيات مرنة لأدوار متعددة.

## الملفات
| المسار | الوصف |
|---|---|
| `index.html` | التطبيق الكامل (ملف واحد) |
| `supabase/schema.sql` | سكربت قاعدة البيانات (جداول + RLS + Realtime) |
| `supabase/manage-users/index.ts` | دالة إدارة المستخدمين (Edge Function) |
| `docs/SETUP.md` | دليل الإعداد خطوة بخطوة |

## النشر السريع
1. نفّذ `supabase/schema.sql` في SQL Editor بمشروعك
2. انشر دالة `manage-users` واتبع `docs/SETUP.md`
3. فعّل GitHub Pages من Settings ← Pages على هذا المستودع
4. افتح الرابط وأدخل إعدادات الاتصال من تبويب «النسخ الاحتياطي والإعدادات»
